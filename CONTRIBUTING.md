# Contributing

Thanks for contributing!\
Please follow these guidelines when submitting changes.

## Branches & Commits

- Use **[Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/)** for both branch names and commit messages.
- All Pull Requests must target the **`dev` branch**.
- Keep each PR focused on **one feature, bug fix, or logical change**. Do not combine unrelated changes.

## Pull Requests

- Write a **clear and proper PR description** explaining what changed and why.
- When possible, include **images or videos** demonstrating visual or functional changes.
- Run `npm run fix` before submitting to ensure the code is properly formatted.
- PRs are **manually reviewed by a human**. Please allow some time for review.

## AI-Assisted Development

AI tools are allowed, but you are responsible for the code you submit.

- **Understand and test** any code generated or modified by AI before submitting it.
    - Do not submit code you don't understand.
- Remove **useless, unnecessarily verbose or redundant AI-generated comments**.

---

> All contributions are appreciated, however the acceptance and merging of contributions is at the author's discretion and based on what is considered beneficial to Textract.

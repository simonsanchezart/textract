# Textract

Texture extractor from photos — reference & shortcuts

## Basic workflow

1. **Load** — bring in one or more photos on the left (Mark) canvas.
2. **Mark** — click 4 corners around the texture you want to extract.
3. **Convert** — extract the marked region(s) into flattened images on the right (Atlas) canvas.
4. **Export** — arrange and export the extracted textures from the Atlas canvas.

## Shortcuts

### General & navigation

| Action                | Shortcut                               |
| --------------------- | -------------------------------------- |
| Zoom stage            | Scroll wheel                           |
| Pan canvas            | Scroll-wheel click + drag / drag stage |
| Context menu          | Right click                            |
| Select all            | `Cmd+A` / `Ctrl+A`                     |
| Delete selected image | `Delete`                               |

### Mark canvas (left panel)

| Action                                | Shortcut                       |
| ------------------------------------- | ------------------------------ |
| Load images                           | `Shift+A`                      |
| Add mark point (on image)             | `Cmd+Click` / `Ctrl+Click`     |
| Reset point selection (while marking) | Right click                    |
| Process / convert marks               | `Shift+R`                      |
| Remove mark (on mark)                 | `Alt+Click`                    |
| Undo                                  | `Cmd+Z` / `Ctrl+Z`             |
| Redo                                  | `Shift+Cmd+Z` / `Shift+Ctrl+Z` |

### Atlas canvas (right panel)

| Action          | Shortcut                       |
| --------------- | ------------------------------ |
| Export atlas    | `Cmd+E` / `Ctrl+E`             |
| Export selected | `Cmd+S` / `Ctrl+S`             |
| Undo            | `Cmd+Z` / `Ctrl+Z`             |
| Redo            | `Shift+Cmd+Z` / `Shift+Ctrl+Z` |

Textract

Texture extractor from photos — reference & shortcuts

Basic workflow

  1. Load — bring in one or more photos on the left (Mark) canvas.
  2. Mark — click 4 corners around the texture you want, as a straight quad, a point-grid grid mark, or a bezier-edge mark (see below).
  3. Convert — extract the marked region(s) into flattened images on the right (Atlas) canvas.
  4. Export — arrange and export the extracted textures from the Atlas canvas.

Curved surfaces

A regular (quad) mark assumes the texture lies on a flat plane. If it's actually wrapped around something curved — a label on a bottle, a sign on a curved wall — use grid mode or bezier mode instead. Both flatten curved surfaces; which one to reach for depends on the shape:

  • Bezier mode (recommended for most curved surfaces) — shape 4 curved edges with draggable handles, like Photoshop's Warp tool. Fewer control points, smoother by construction, and works for any curved region: bottles, curved signs, curved walls.
  • Grid mode — a full NxM grid of individually-draggable points. More manual work, but useful for a mostly-flat shape that's only bent at the edges (e.g. a box or panel), where a handful of straight segments describes the shape better than a smooth curve would.

Bezier mode

  1. Click the bezier-mode toolbar icon (or Shift+G to cycle quad → grid → bezier) to switch to bezier mode.
  2. Place the mark the same way as a quad: click the 4 corners around the curved region. It starts as a straight-edged rectangle — no curve yet.
  3. Each of the 4 edges has 2 small handle points connected to their corner by a thin guide line. Drag a handle outward to bow that edge to match the curve you see in the photo. Handles are independent, not mirrored across a corner — a corner can stay a sharp point even while its adjacent edges curve.
  4. Convert as usual — no separate "straighten" step needed. The flattened output is produced directly from the curved shape you traced.

Grid mode

  1. Click the grid-mode toolbar icon (or Shift+G to cycle quad → grid → bezier) to switch to grid mode.
  2. Adjust the Rows / Cols steppers that appear — this sets how many control points make up the mesh. More points trace a curve more precisely, but are more work to place.
  3. Place the mark the same way as a quad: click the 4 corners around the curved region. This seeds a straight interior grid between them.
  4. Drag the interior points (not just the corners) so the grid lines follow the actual curve in the photo — e.g. bow the middle rows outward to match a bottle's curvature.
  5. Convert as usual. The backend flattens the curved grid into a rectangular image, following the shape you traced rather than a single flat plane.
Undo (Cmd+Z on macOS, Ctrl+Z elsewhere) and redo (Shift+Cmd+Z on macOS, Shift+Ctrl+Z elsewhere) both work while shaping a grid — don't hesitate to drag a point and adjust if the curve isn't quite right.

Smoothing a curve (optional)

A grid mark only draws straight lines between the points you place, which can look faceted at low grid density. To smooth it out without placing more points:

  1. Select the points along the part of the curve you want smoothed — e.g. an entire interior row or column tracing a bottle label's curvature, but not the sharp corners — using Shift+Click to build a multi-selection.
  2. Press S to mark them smooth. A run of points along a row or column only curves where both ends of that segment are marked smooth; a point you leave unmarked stays exactly as sharp as before, and the curve fades back to straight as it approaches it.
  3. Use - / = to loosen or tighten the curve for the current selection (tight tension looks the same as a straight line; loose tension bows further off the chord).
  4. Smoothing only bends the path between points you've already placed — it doesn't invent curvature on its own. If your points are placed in a straight line, marking them smooth won't visibly change anything; drag the interior points to actually trace the curve you see in the photo first, then smooth them so the mesh follows that shape instead of the straight chords between them.
